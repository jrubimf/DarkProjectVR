# DarkProjectVR

## AI usage
AI was used for everything in this project: code, reverse engineering, assets and docs.

VR for Thief Gold and Thief 2.

## Installation

1. Start from a clean install of the game.
2. Unzip the release anywhere.
3. Run `DarkProjectVR.exe`.

## Known issues

**Oculus Link crashes on launch.** The Oculus OpenXR runtime has no 32-bit library, and the game is 32-bit.

Fix: open SteamVR → Settings → OpenXR → **Set SteamVR as OpenXR Runtime**, then launch again.
